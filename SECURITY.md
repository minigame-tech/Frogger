# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ Yes             |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not open a public issue**.

Instead, report it privately by emailing:

📧 **[cipriano.salvatore@example.com](mailto:cipriano.salvatore@example.com)**

Please include the following in your report:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact or severity.
- Any suggested fix (if available).

## Response Timeline

- **Acknowledgment:** within **48 hours** of receiving the report.
- **Status update:** within **7 days**, including an assessment of the issue.
- **Fix release:** as soon as a patch is ready, depending on severity.

## Scope

This policy applies to the code hosted at [SalvoCodes-developer/Frogger](https://github.com/SalvoCodes-developer/Frogger).

Third-party dependencies (e.g., Pygame) are outside the scope of this policy. If you find a vulnerability in a dependency, please report it to the respective maintainer.

## Acknowledgments

We appreciate responsible disclosure. Contributors who report valid security issues will be credited in the project (unless they prefer to remain anonymous).
